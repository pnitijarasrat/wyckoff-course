Pinning the profile: anchors and range age

Where to pin a structure’s Volume Profile, which daily changes to ignore, and how much a range’s age lets you trust its levels.

1 · Three ways to pin a profile

KindCountsChanges daily?
Visible rangeThe bars on screenYes: the window slides (scroll, zoom, a new day). Noise
AnchoredA start bar → todayYes: the window grows. The auction, still developing
Fixed / measuredStart bar → end barNo

Sources: Wyckoff 2.0 pp.196–201, 210. Deepvue’s guide uses the same three names.

2 · Where to pin it

The stock is…Pin itStartEnd
Inside its rangeAnchoredSC / BCToday
Broken out, waiting for the testFixedSC / BCBar before the breakout
Broken out, back insideAnchoredSC / BCToday
Trending, no rangenone(keep the last range’s fixed profile)—
  • Never start in the trend before the climax: those bars make a P or b shape (pp.209–211).
  • The test after a breakout comes back to the range’s VAH/VAL, then its VPOC (pp.216–217).
  • Value areas overlap → one profile over both (p.198).

3 · Range age (my working rule)

AgeEach new day ≈LevelsLean on
< 4 weeks (20 bars)1/10 – 1/20 of the volumeProvisional, a zoneSC, AR, ST
1–2 months1/20 – 1/40Firming upBoth
2–3 months+under 1/40Settled: a move means value is shiftingThe profile

Three real ranges (ANET, GOOGL, META, daily bars): the VAH/VAL moved about 3–4% of the range’s height per day in days 5–15, and about 1% after day 45.

4 · A few weeks old: which kind?

It is…Plan withShort range’s job
Inside a bigger rangeThe big range, from its climaxPhase B resting; timing
A new step after a markupThe new range, from the markup’s topThe live structure. The old range’s fixed profile = the next floor (pp.182–183)

5 · The watchlist routine

  1. Label each stock: inside, broke out, no range.
  2. Pin: anchored or fixed, as in §2. Count the bars.
  3. Note: XYZ · since SC Jul 14 (62 bars, mature) · VAH · VPOC · VAL
  4. Daily: read the movement only on mature anchored profiles.
  5. Re-pin only on a breakout, a failed breakout, or a new range.
